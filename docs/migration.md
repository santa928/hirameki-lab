# SitesからGitHub Pagesへの移行

## 保持した内容

- REQ-001: 既存120ゲーム・8,209ステージ・82,090問、全ゲームアセット、5テーマの目標と固定シードを保持。
- REQ-002: ステージ・3ぷん・じっくり、プロフィール6人、ヒント・動くお手本・タッチ操作を保持。
- REQ-003: サーバー保存を端末内保存へ変更。セッションID単位で重複を防ぎ、成績と最高スターを集計。
- REQ-004: バックアップの書き出しと追加読み込み。完全検証後に1トランザクションで追加し、エラー時は全体を取り消す。
- REQ-005: GitHub Pagesのサブパス対応、CI成功後のみ公開。既存Sites版は保持。

REQ-001〜005の削除・保留はありません。ゲーム数やステージ数を今回の移行で減らしていません。

## 保存仕様

IndexedDB `hirameki-local-records-v1` に検証済みのプレイ記録と日時を保存します。プロフィール単位で正解数・プレイ数・到達レベル・3分モード最高点・各ステージ最高スター・日本時間のプレイ日数を集計します。保存成功はトランザクション完了後に表示します。複数タブへ変更を通知します。

バックアップ形式は `format: hirameki-lab`、`version: 1`。6人分のプレイ記録を含みます。上限32MB・100,000記録。不正なJSON、未対応形式、不正なゲーム名・数値、同じIDの矛盾を拒否します。端末保存を読み込めない場合は画面の未保存記録のみを救出し、その制限を案内します。

音・お気に入り・選択プロフィールはブラウザの設定として保持します。サーバー同期、Sites版記録の自動移行、ブラウザデータ削除後の自動復旧は対象外です。Safariのホーム画面追加に対応しますが、ネットワーク不要の起動を保証するサービスワーカーは提供しません。

## 難易度と検証の意味

レールは入口・出口が異なる列で、想定解以外も含む曲がり・経路長の下限を検査します。積み木は初級から高さを持ち、後のテーマで奥行き・段・欠けた箱を使います。全問の正答・選択肢・問題内容の重複と、テーマ内の構造スコアの順を自動検査します。別の概念へ進むテーマ境界では基本に戻ります。全問を人の目で実プレイしたという検証ではありません。

既存ソースには独自実装の問題・図・判定を保持しています。参考作品のブランド・素材・問題データの配布は行いません。公開ソースはSitesの内部設定・認証・個人情報・開発ログ・生成検証成果物を含めず、静的アプリと再現可能な検査コードだけを管理します。

## 性能と公開条件

既存ゲームを保持するため大きな問題バンクを含みます。初回のJavaScript転送はgzipで約870KBです。教育効果の評価や包括的な性能保証は対象外ですが、代表的なデスクトップ・モバイルで画面と実操作を確認します。公開条件は独立レビュー、関連lint/型検査/全テスト/全問検査/build成功、公開コミットとPages成果物の一致、主要ゲームと保存・復元の本番確認です。
